Guide du studio

1. Crée une vidéo et copie le prompt de départ dans ton agent (Claude Code ou Codex), ouvert sur ce dossier. 2. Colle le script reçu ici et tourne. 3. Demande le montage avec le chemin de la prise indiqué dans le prompt. 4. Importe le montage, pose tes retours aux bons instants et copie-les dans le chat de montage.

Les boutons de copie préparent les instructions. Ils ne lancent pas un agent et ne modifient pas automatiquement la vidéo.
